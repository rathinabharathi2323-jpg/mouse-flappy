# mouse-flappy
Mouse Flappy is a fun and challenging 2D arcade game developed using Python and Pygame. In this game, the player controls a cute mouse and helps it fly through obstacles while avoiding mouse traps.
MOUSE ESCAPE! – Flappy Mouse Game
An Exciting 2D Arcade Game Developed Using Python and Pygame
📌 About the Project

MOUSE ESCAPE! is a fun and interactive 2D arcade game inspired by the Flappy Bird gameplay concept. It is developed using Python and the Pygame library.

In this game, players control a cute mouse that must jump through gaps between dangerous mousetrap obstacles. The player needs to avoid collisions, survive as long as possible, and achieve the highest score.

📥 Installation and Setup
Step 1: Install Python

Download Python from the official website:

https://www.python.org/downloads/

Step 2: Install Pygame

Open Command Prompt or Terminal and execute:

bash
pip install pygame

Step 3: Clone the Repository
bash
git clone https://github.com/YOUR-USERNAME/Mouse-Escape.git

Step 4: Navigate to the Project Folder
bash
cd Mouse-Escape

Step 5: Run the Game
bash
python main.py
